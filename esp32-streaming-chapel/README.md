# ESP32 megatexture chapel

The [repository README](../README.md) covers building, board/display configuration,
camera controls, rendering, performance and attribution. This directory is the
ESP-IDF project; the shared components must remain one directory above it.

The converted chapel geometry and baked textures are from James D. Lambert's
[n64brew2023](https://github.com/lambertjamesd/n64brew2023), under its
[MIT licence](../LICENSE.n64brew2023). See [asset provenance](generated/README.md).
